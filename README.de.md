# TreeView

Deutsch | [English](README.md)

IP-Symcon-Bibliothek von Ueli Schweizer / Cassanis Automation.

| Modul | Beschreibung |
|---|---|
| [TreeView](TreeView/README.de.md) | HTML-Kachel für beliebig tief verschachtelte Hierarchien mit Live-Werten, Icons und Navigationszielen |

## Voraussetzungen

IP-Symcon ab Version 8.1. Ab 9.1 kann die Kachel zusätzlich im Vollbild-Modus angezeigt werden.

## Installation

Über den Module Store oder im Module Control mit der URL
`https://github.com/wowbagger60/TreeView`.
